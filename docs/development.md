## 一. 需求分析

该系统用于常州骐临金属表面处理有限公司管理客户订单、生产排产、货物入库及出库流程，具体功能包括但不限于：

- 订单统一管理，由货物入库时自动建立客户订单，并保留入库凭据
- 客户订单应明确客户需求、交付日期、货物品类、计量数据等必要信息，方便工人生产
- 管理层实现自由排产，根据实际情况确定生产优先级
- 实现货物出库跟踪并保留货物交付凭据

### 1.1 权限设计

- [x] 最少区分管理员与普通用户，是否区分具体工作指责尚不确定

#### 1.1.1 管理员权限

- 所有信息可读
- 排产规划
- 入库操作
- 出库操作
- 修改订单信息
- 创建用户，删除用户
- 新增计量单位，删除计量单位

#### 1.1.2 员工权限

- 排产列表可读
- 出库列表可读
- 出库可操作
- 入库可操作

### 1.2 建立订单

建立订单即入库，由工厂员工或管理层完成，需要录入以下字段：

- 订单编号（自动生成）
- 入库时间 （自动生成）
- 客户公司
- 规格型号
- 交付时间
- 处理方式
- 优先级
- 备注
- 数量
- 单位
- 称重
- 图片留存 （最多三张）
- 更新时间 （更新时生成）

订单页面展示内容（按照顺序排列）：

| Column                    | Type     | Description                                            |
| ------------------------- | -------- | ------------------------------------------------------ |
| 规格型号                  | String   | 描述入库货物类型                                       |
| 优先级                    | Enum     | 紧急、高、中、低                                       |
| 交付日期（可为空）        | Datetime |                                                        |
| 处理类目                  | String   | 镀锌、镀镍、镀铬...                                    |
| 处理类型                  | String   | 服务于镀锌类目，有蓝白锌、彩锌、三价彩...              |
| 是否封闭                  | Boolean  | 服务于镀锌订单                                         |
| 备注                      | String   | 保存额外信息                                           |
| 计量单位                  | String   | 如个、件、框...                                        |

| 入库称重                  | Int      | 统一为公斤                                             |
| 入库凭据（图片，至多3张） | png\jpg  | 入库时拍照留存                                         |
| 客户公司                  | String   |                                                        |
| 订单编号                  | String   | ORD-YYYYMMDD-XXX                                       |
| 联系人                    |          |                                                        |
| 联系电话                  |          |                                                        |

### 1.3 出库流程

出库以现有订单为基础，出库时需要明确以下信息，单据回收在出库单建立时默认为否，后续可修改为是并添加图片留存（仅可修改一次）

出库表单需包含：

| Field    | Type | Description                  |
| -------- | ---- | ---------------------------- |
| 订单编号 |      | 员工出库时选择对应订单       |
| 出库单号 |      | 自动生成 OUT-YYYY-DDYY-XXX   |
| 出库数量 |      | 选择部分出库时需提供该字段   |
| 出库称重 |      | ...                          |
| 出库人   |      | 根据登录帐号自动生成         |
| 出库留存 |      | 照片留存，至多3张            |
| 单据回收 |      | 填写出库时不需提供，后续补充 |
| 出库时间 |      | 系统自动生成                 |
|          |      |                              |

### 1.4 排产面板

排产工作面向当前所有未出库货物，管理员在订单列表中选择未出库或未完全出库订单放入排产列表
